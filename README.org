#+title: Personal Guix configuration files

This repository contains the configuration files for all machines that use Guix. All configuration files (~home-environment~ and ~operating-system~ records for all of my machines) may be found under =src/krisb/config=.

All personally-packaged packages may be found under =src/krisb= (with the exception of =src/krisb/config=). (These are for my use; they are not guaranteed to be regularly updated nor high-quality (and likely won't!).)

* Maak (Guile's =Makefile=)

This project uses [[https://codeberg.org/jjba23/maak][Maak]], which is a Guile-version of Make. Its usage is incredibly similar; list all Maak targets with ~maak --list~.

All regularly done Guix commands for building, reconfiguring, and so on are standardized in [[file:maak.scm][the maak.scm file]].

Additionally, tasks that are relevant only to a particular machine (e.g., ~home~, ~system~, ~pull~) are automatically specified to the current machine by parsing the output of the ~hostname~ CLI command.
